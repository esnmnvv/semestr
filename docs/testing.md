# Протокол проверки этапа 20%

Дата: 27 октября 2026, Asia/Bishkek. Локальная разработка, macOS ARM64, Node.js 24.11.1, PostgreSQL 16.14, Chromium (Playwright). Зависимости зафиксированы в package-lock.json.

## Автоматические проверки

- `npm test`: 5 проверок — допустимые значения, обязательные поля, регистр почты, границы пароля, неверные типы и часовые пояса, хеширование и проверка пароля.
- `npm run test:api`: 11 проверок на настоящей PostgreSQL — регистрация, уникальность email без учёта регистра, валидация, сохранение профиля, защита другого пользователя, FORCE RLS для владельца таблицы, ограничения БД, запрет чужого Origin, выход и сохранение сессии при новом запуске сервера, Secure cookie и CSP в production, ограничение частоты неудачных попыток входа.
- `npm run test:e2e`: 5 браузерных сценариев — полный цикл регистрации/входа/профиля/выхода; сообщения у полей и показ пароля; сохранение полей после имитированного HTTP 503 и успешная повторная запись в настоящую БД; отмена правок; работа всех страниц на ширине 360 px; настольные страницы и локальные шрифты.
- `npm run build`: production-сборка проходит.
- При установке npm не сообщил об известных уязвимостях зависимостей.

Результат: все указанные проверки пройдены. В основном браузерном сценарии нет ошибок JavaScript; в мобильном сценарии нет горизонтальной прокрутки. Тестовые пользователи и их сессии удалены после испытаний.

## Визуальная проверка

Снимки экранов в `screenshots/`: регистрация и вход на компьютере и телефоне, обзор, профиль на компьютере и телефоне. Проверены расположение полей, длинная почта, переносы текста, кнопки сохранения, боковая и мобильная навигация. Вспомогательные подписи имеют меньший кегль, основной текст и поля — 16 px и больше.

## Границы проверки

Испытания выполнены в локальном Chromium, не на физических телефонах, Safari или Firefox. Нагрузочные испытания на 30 пользователей и проверки будущих предметов, заданий и календаря не выполнялись: они относятся к следующим этапам. Отправка email и Supabase не используются. Проверка TLS внешнего сервера, публикация и восстановление удалённой БД не выполнялись.
